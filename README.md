# Pokémon Redstone: downloads

Minecraft Steve with survival in Pokémon FireRed's Kanto: mine, craft, build, survive the night, catch POKéMON, go to the Nether and The End, and play co-op with friends in huge generated worlds.

Play in your browser at **https://pokemon-redstone.pages.dev**, or download the app below to play offline (co-op still works online, with app and browser players in the same rooms).

**Get it from [Releases](../../releases/latest).** Pick the file for your device:

| Device | File |
|---|---|
| Mac with Apple Silicon (M1 or newer), macOS 13+ | `PokemonRedstone-1.0.0-mac-arm64.zip` |
| Mac with an Intel chip, macOS 13+ | `PokemonRedstone-1.0.0-mac-x64.zip` |
| Windows 10 or 11 (64-bit) | `PokemonRedstone-1.0.0-win-x64.zip` |
| Linux (64-bit x86) | `PokemonRedstone-1.0.0-linux-x64.tar.gz` |
| Android 7 or newer, including Retroid, AYN and Anbernic handhelds | `PokemonRedstone-1.0.0-android.apk` |

Controllers work (Xbox, PlayStation, Nintendo pads and handheld buttons).

Install steps for every platform, the controller layout, where saves live and how to check the downloads are in [HOW-TO-INSTALL.md](HOW-TO-INSTALL.md).
